# ThinkerCafe Organization Profile

This repository contains the organization profile for ThinkerCafe on GitHub.

The profile is displayed at: https://github.com/ThinkerCafe-tw

## Structure

- `profile/README.md` - Organization profile page (Traditional Chinese, default)
- `profile/README_EN.md` - Organization profile page (English)
- `profile/README_JA.md` - Organization profile page (Japanese)

## Multi-language Support

GitHub organization profiles support multiple languages through separate files:
- The default `README.md` is shown to all visitors
- Additional language versions can be accessed directly via their file paths
- Future GitHub features may enable automatic language switching

## Updating the Profile

To update the organization profile:
1. Edit the appropriate README file in the `profile/` directory
2. Commit and push your changes
3. The profile will update automatically on GitHub
