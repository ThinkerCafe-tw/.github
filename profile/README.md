## 關於

ThinkerCafe 是思考者咖啡有限公司旗下計畫。公司目前由創辦人 Cruz Tang／湯明軒一人經營，沒有現行團隊，也沒有開放職缺或對外營業門市。

我們探索 AI 如何進入真實生活，同時保留人的主導權，以及不同情境間清楚的身份、內容、同意與資料邊界。

## 三項計畫

- **ThinkerCafe**：AI、生活與一人公司實驗的公開入口。
- **HumanOS**：以人為主體的個人 AI 系統研究與實作。
- **苗栗好朋友**：服務苗栗在地生活情境的計畫。

三項計畫同屬思考者咖啡有限公司，但不代表使用者身份、內容、同意或資料會自動互通。
