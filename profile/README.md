## 關於公司

思考者咖啡是一家由 Cruz／湯明軒創辦的人本 AI 公司，打造 ThinkerCafe 與 HumanOS，讓 AI 先理解人的脈絡、取得本人同意，再協助整理、行動與回看。

公司目前由創辦人一人經營，沒有現行團隊、開放職缺或對外營業門市。本 GitHub 組織是工程與開源入口，不取代公司母品牌的完整定位。

## 品牌與產品架構

- **ThinkerCafe**：面向人的產品與 managed service。使用者不用先整理好問題，可用語音或文字留下脈絡；AI 協助整理，AI 已處理與 Cruz 已親閱必須分開標示。
- **HumanOS**：模型中立、可 Fork 的開源協議／Kernel，處理同意、候選行動、結果回看、Protocol 與回滾。目前僅為工程候選與開源資格驗證中，不宣稱已改善人生或取得管理人的權力。
- **CruzOS**：Cruz 的私人 HumanOS Fork 與內部 intelligence qualification；不是首次訪客產品，也不公開私人脈絡。
- **苗栗好朋友**：同公司培育的苗栗在地服務；其公開身分、使用情境、資料與記憶、金流及對外承諾彼此獨立。
- **Podcast／自媒體**：公司的內容與 Build in Public 層，記錄 AI 進入真實生活、HumanOS 研究與一人公司實驗；不是公司全部定位。

同屬一家公司，不代表使用其中一項服務時，身分、內容、同意、資料、記憶、金流或承諾會自動流向另一項服務。
