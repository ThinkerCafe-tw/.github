## 会社について

**思考者咖啡有限公司**は、Cruz Tang／湯明軒が創業した人間中心の AI 会社です。ThinkerCafe と HumanOS を開発し、AI がまず本人の文脈を理解し、本人の同意を得たうえで、整理・行動・結果の振り返りを支援します。

現在は創業者が一人で運営しており、現行のチーム、募集中の職種、一般向けの実店舗はありません。この GitHub Organization はエンジニアリングとオープンソースの入口であり、会社全体のアイデンティティに代わるものではありません。

## ブランドとプロダクトの構成

- **ThinkerCafe** — 人に向き合うプロダクト兼 managed service。利用者は問題を事前に整理せず、音声またはテキストで文脈を残せます。AI が処理した状態と Cruz が本人として確認した状態は、明確に分けて表示します。
- **HumanOS** — 同意、候補行動、結果の振り返り、Protocol、ロールバックを扱う、モデル中立で Fork 可能なオープンソースのプロトコル／Kernel。現在はエンジニアリング候補およびオープンソース適格性の検証段階であり、人生を改善した実績や人を管理する権限を主張しません。
- **CruzOS** — Cruz のプライベートな HumanOS Fork と社内 intelligence qualification。初回訪問者向けの製品ではなく、私的な文脈は公開しません。
- **苗栗好朋友** — 同じ会社が育てる苗栗の地域サービス。公開上のアイデンティティ、利用場面、データと記憶、金流、対外的な約束は独立して扱います。
- **Podcast／メディア** — 実生活に入る AI、HumanOS の研究、一人会社の実験を記録するコンテンツと Build in Public の層。会社全体の位置づけそのものではありません。

同じ会社に属していても、利用者のアイデンティティ、コンテンツ、同意、データ、記憶、金流、約束がサービス間で自動的に移転することはありません。
